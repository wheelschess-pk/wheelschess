# WheelsChess

WheelsChess is a vehicle marketplace project built with
Next.js, TypeScript, Tailwind CSS, PostgreSQL and Prisma.

## Features

- Vehicle categories and listings
- User registration and login
- Seller dashboard
- Admin listing approval
- Buyer and seller messaging
- Showpiece and spare parts orders
- WhatsApp support

## Requirements

- Node.js
- npm
- PostgreSQL

## Installation

1. Clone the repository.
2. Install dependencies:

   npm install

3. Copy .env.example to .env.
4. Configure your database connection.
5. Generate Prisma Client:

   npx prisma generate

6. Start the development server:

   npm run dev

Open http://localhost:3000 in your browser.

Database migrations and authentication setup are
completed in their respective development stages.
